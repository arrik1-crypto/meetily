#   <library base name> <symbol>
# A base name covers every CPU build of that library: libmeetily_native.so
# and libmeetily_native_v82.so must both export every line. Whisper, the
# speech gate and the local LLM are one library per CPU level, so there is one
# base name.
#
# NativeExportsTest (unit tests) keeps this in step with the Kotlin natives,
# read from the compiled classes, and with the Java_ functions in this
# directory; on a mismatch it prints the corrected file.
# scripts/check_jni_exports.py fails the CI build when a built library lacks
# one of these, or exports anything jni_exports.map does not allow.
