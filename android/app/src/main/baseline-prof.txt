# Baseline Profile for Recap: cold start, opening a meeting and scrolling
# its transcript. AGP compiles this file, merged with the profiles the
# AndroidX libraries ship in their AARs, into assets/dexopt/baseline.prof and
# baseline.profm in the APK and the bundle. ART compiles it when Play
# installs the app; for a sideloaded copy androidx.profileinstaller hands it
# to ART on the first run, and ART compiles it at its next background
# optimisation.
#
# Hand-curated from the code, not recorded on a device: no startup time has
# been measured with or without it. Rules name classes and methods as
# compiled, before R8, which rewrites them for the optimised release build.
# AGP drops a rule that matches nothing without a word, so
# BaselineProfileTest checks that every line parses and that every app
# class and method named here still exists.
#
# Syntax: FLAGS then Lclass;->method(params)return, or Lclass; alone for a
# class used during start-up. H hot (compiled ahead of time), S start-up,
# P after start-up. ? one character, * any run within a name, ** any run
# across packages and whole signatures. # starts a comment line.

# Cold start. Application.onCreate and what it runs (crash capture, the
# engine-default migration, night mode, the app lock's lifecycle
# callbacks, the system-sounds backstop's callback and its first-resume
# look, the start-up threads' entry points), then the home screen up
# to its first frame: MainActivity, the library list's adapter and rows,
# the light listing read and parsed on the library-load worker with the
# search index built beside it, the search box and filter chips, the
# progress banners, and the edge-to-edge and accessibility helpers every
# screen uses.
